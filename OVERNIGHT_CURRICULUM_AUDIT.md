## Sample (placeholder) modules

**1,072 chapters carry a sample module** rather than a generated lesson. Each is
written with `isSample: true` and renders a banner above the content:

> ℹ **Interactive Practice Module — Sample Lesson**

They are used only where a real lesson could not be grounded:

- **Grades 1–5** — the readers are picture-led; ingestion yields too little text
  to build a lesson from (Grade 5 English had 5 usable topics in total).
- **Hindi / Urdu / Sanskrit** — the PDFs carry Kruti-Dev legacy font encoding,
  not Unicode. `"fpfM+;k vkSj"` is Devanagari rendered in a non-Unicode font, so
  text extraction returns Latin gibberish (0 Devanagari codepoints). The text IS
  recoverable, but needs a Kruti-Dev → Unicode mapping table with matra
  reordering — real work, not a quick fix. Sanskrit has no PDFs at all below G9.
- **Grade 11 English (Hornbill)** — `kehb1` is absent from disk **and from
  Supabase**. It was never uploaded. Snapshots and Woven Words are present.

Around each sample the structure is genuine: chapter title, chapter number and
the textbook PDF all come from the real book, so the reader panel opens the
actual pages.

## Source verification

All 1,491 PDFs in the Supabase `ncert-books` bucket were compared against the
local store: **every one already existed locally**. Supabase held no additional
books, so no new source material was recoverable from it.
