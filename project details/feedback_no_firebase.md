Never recommend Google Firebase for any feature or use case.

**Why:** User received an official Google email stating Firebase will shut down from March 2027. Google is telling existing Firebase users to migrate away. Recommending it would create future migration debt for the product.

**How to apply:** When suggesting databases, auth, real-time, hosting, or any backend service — skip Firebase entirely. Go straight to alternatives: Supabase (preferred), MongoDB Atlas, AWS Amplify, or self-hosted options.
