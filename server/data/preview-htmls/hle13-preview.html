Q1. (1) దుర్గ ముగ్గులు బాగా పెడుతుంది.

Answer =
Identify words in the sentence that contain 'గ' (ga) or 'ట' (ta) ottu (subscript letters).
✅ Solution
The words with 'గ' ottu are దుర్గ (durga, 'గ' with 'గ' ottu) and ముగ్గులు (muggulu, 'గ్గు' which is 'గ' with 'గ' ottu).

Q2. (2) చెట్టు కింద పాము పుట్ట ఉంది.

Answer =
Identify words in the sentence that contain 'గ' (ga) or 'ట' (ta) ottu (subscript letters).
✅ Solution
The words with 'ట' ottu are చెట్టు (cheṭṭu, 'ట్ట' which is 'ట' with 'ట' ottu) and పుట్ట (puṭṭa, 'ట్ట' which is 'ట' with 'ట' ottu).

Q3. (3) అగ్గిమీద గుగ్గిలం

Identify words in the sentence that contain 'గ' (ga) or 'ట' (ta) ottu (subscript letters).
✅ Solution
The words with 'గ' ottu are అగ్గిమీద (aggimeeda, 'గ్గి' which is 'గ' with 'గ' ottu) and గుగ్గిలం (guggilam, 'గ్గి' which is 'గ' with 'గ' ottu).

Q9. 1. గద గాలిలో ఎగురుతుంది.

Answer =
Add the 'ద' ottu to the underlined 'ద' in 'గద' to form the correct word for a kite (bird).
✅ Solution
The underlined letter 'ద' in 'గద' (gada - weapon) needs a 'ద' ottu to become 'గద్ద' (gadda - kite, the bird). So the corrected sentence is: గద్ద గాలిలో ఎగురుతుంది.

Q10. 2. పావని వయసు రెండేళ్ళు.

Answer =
Check if the underlined letter 'ళ్ళు' already has a correct ottu. If so, rewrite the sentence as is.
✅ Solution
The word 'రెండేళ్ళు' (rendeḷḷu - two years) is already correctly spelled with the 'ళ్ళ' (ḷḷa) ottu. No additional ottu is needed, so the sentence is rewritten as is: పావని వయసు రెండేళ్ళు.

Q11. 3. బొద్దింక ఒక కీటకం.

Answer =
Determine if the underlined letter 'క' in 'కీటకం' requires an ottu for correct spelling. If not, rewrite the sentence as is.
✅ Solution
The word 'కీటకం' (kīṭakam - insect) is correctly spelled and does not require an ottu on the underlined 'క'. So the sentence is rewritten as is: బొద్దింక ఒక కీటకం.
