Task 1 · Solve each problem and use the code below to complete the blanks and discover the secret message.

a) 326 + 419 = ___

Answer =
Add the ones: 6 + 9 = 15. Write 5, carry over 1. Add the tens: 2 + 1 + 1 = 4. Add the hundreds: 3 + 4 = 7.
✅ Solution
326 + 419 = (300 + 20 + 6) + (400 + 10 + 9) = (300 + 400) + (20 + 10) + (6 + 9) = 700 + 30 + 15 = 745

b) 317 - 258 = ___

Answer =
Subtract the ones: 7 - 8. Regroup 1 ten to make 17 - 8 = 9. Subtract the tens: 0 - 5. Regroup 1 hundred to make 10 - 5 = 5. Subtract the hundreds: 2 - 2 = 0.
✅ Solution
317 - 258: Regroup 317 to 2 hundreds, 10 tens, 17 ones. 17 - 8 = 9, 10 - 5 = 5, 2 - 2 = 0. So, 317 - 258 = 59.

c) 628 + 794 = ___

Answer =
Add the ones: 8 + 4 = 12. Write 2, carry over 1. Add the tens: 2 + 9 + 1 = 12. Write 2, carry over 1. Add the hundreds: 6 + 7 + 1 = 14.
✅ Solution
628 + 794 = (600 + 20 + 8) + (700 + 90 + 4) = (600 + 700) + (20 + 90) + (8 + 4) = 1300 + 110 + 12 = 1422

d) 900 - 278 = ___

Answer =
Subtract the ones: 0 - 8. Regroup 1 ten to make 10 - 8 = 2. Subtract the tens: 9 - 7 = 2. Subtract the hundreds: 8 - 2 = 6.
✅ Solution
900 - 278: Regroup 900 to 8 hundreds, 9 tens, 10 ones. 10 - 8 = 2, 9 - 7 = 2, 8 - 2 = 6. So, 900 - 278 = 622.

e) 569 + 650 = ___

Answer =
Add the ones: 9 + 0 = 9. Add the tens: 6 + 5 = 11. Write 1, carry over 1. Add the hundreds: 5 + 6 + 1 = 12.
✅ Solution
569 + 650 = (500 + 60 + 9) + (600 + 50 + 0) = (500 + 600) + (60 + 50) + 9 = 1100 + 110 + 9 = 1219

f) Use the answers from (a) to (e) and the code to fill in the blanks: ___ - ___ / ___ - ___ / ___ - ___

Answer =
Match each answer to the code: 745=M, 59=E, 1422=Y, 622=R, 1219=Y, 427=X.
✅ Solution
From the code: 745=M, 59=E, 1422=Y, 622=R, 427=X. So, 745 - 59 = M - E, 1422 - 622 = Y - R, 1219 - 427 = Y - X. The secret message is M - E / R - R / Y - X.

Task 2 · Solve the following word problems using the appropriate number operation.

a) There are 507 crows in the field. A loud sound scares 224 of them away. How many crows are left?

Answer = crows
Subtract the number of crows scared away from the total number of crows.
✅ Solution
507 - 224 = (500 - 200) + (0 - 20) + (7 - 4) = 300 - 20 + 3 = 283 crows.

b) A market sells 476 apples in one week and 348 apples in the next week. How many apples have been sold in total?

Answer = apples
Add the number of apples sold in both weeks.
✅ Solution
476 + 348 = (400 + 300) + (70 + 40) + (6 + 8) = 700 + 110 + 14 = 824 apples.

Answer =

Task 7 · Calculate the missing digits in these calculations.

a) Find the missing digits: _6_ + 2_7 = 424

Answer =
Start from the ones place: 7 + 7 = 14. Write 4, carry over 1. Then, 6 + 5 + 1 = 12. Write 2, carry over 1. Finally, 1 + 2 + 1 = 4.
✅ Solution
Ones place: 7 + 7 = 14 → write 4, carry 1. Tens place: 6 + 5 + 1 = 12 → write 2, carry 1. Hundreds place: 1 + 2 + 1 = 4. So, 167 + 257 = 424.

b) Find the missing digits: 70_ - 3_6 = 385

Answer =
Start from the ones place: 1 - 6. Regroup 1 ten to make 11 - 6 = 5. Then, 9 - 1 = 8. Finally, 6 - 3 = 3.
✅ Solution
Ones place: 11 - 6 = 5 (regroup 1 ten). Tens place: 9 - 1 = 8. Hundreds place: 7 - 3 = 4, but 701 - 316 = 385. So, 701 - 316 = 385.

c) Find the missing digits: _24 - 1_0 = 264

Answer =
Start from the hundreds place: 3 - 1 = 2. Then, 8 - 2 = 6. Finally, 4 - 0 = 4.
✅ Solution
Hundreds place: 3 - 1 = 2. Tens place: 8 - 2 = 6. Ones place: 4 - 0 = 4. So, 384 - 120 = 264.
