Answer =
Look at the balance scale in the picture. The lower side is heavier.
✅ Solution
The balance scale shows box A is lower than box B, so box A is heavier than box B.

3) What is the weight of box D? __.

Answer =
Look at the balance scale. Box D is equal to box A + box B + box C.
✅ Solution
Box A is 2 kg, box B is 1 kg, and box C is 1 kg. 2 kg + 1 kg + 1 kg = 4 kg, but the scale shows box D is equal to 3 kg. Wait, the scale shows box D = box A (2 kg) + box C (1 kg) = 3 kg. So the weight of box D is 3 kg.

4) Explain how you found out the weight of box D.

Answer =
Look at the balance scale and add the weights of the boxes that balance with box D.
✅ Solution
The balance scale shows box D is equal to box A and box C together. Box A is 2 kg and box C is 1 kg, so 2 kg + 1 kg = 3 kg. Therefore, box D weighs 3 kg.

5) Arrange the boxes in order as per their weight. Begin with the lightest. __.

Answer =
Use the weights you found: Box B = 1 kg, Box C = 1 kg, Box A = 2 kg, Box D = 3 kg.
✅ Solution

c) All About Time

1) Your school starts at 8:30. What time is it half an hour later?

Answer =
Add 30 minutes to 8:30.
✅ Solution
8:30 + 30 minutes = 9:00. So half an hour later is 9:00.

2) If a movie starts at 5:00 and ends at 6:00, how long is it?

Answer =
Subtract the start time from the end time.
✅ Solution
6:00 - 5:00 = 1 hour. So the movie is 1 hour long.
